# Perfica Support

## User support

For ordinary usage problems:

1. confirm you are using an official Perfica build;
2. note the Perfica version;
3. note your Android/iOS version;
4. reproduce the problem if possible;
5. use the built-in bug-report flow or GitHub bug-report form.

Canonical repository:

```text
https://github.com/Veltaluma/Perfica
```

## Bug reports

A useful report includes:

- what happened;
- what you expected;
- exact reproduction steps;
- Perfica version;
- operating system;
- screenshots when relevant.

The built-in report flow allows diagnostic information to be reviewed before
submission.

## Feature requests

Use the GitHub feature-request form.

Describe the underlying problem first, then the proposed solution.

## Security

For vulnerabilities, use `SECURITY.md`.

Do not publish exploit details in an ordinary issue.

## Donations

Perfica is free and open-source software.

An official donation destination has not been selected yet.

The repository deliberately does not contain a fake payment URL or placeholder
account that could be mistaken for an active destination.

When an official donation provider is selected, the project can enable:

```text
README.md donation link
SUPPORT.md donation link
.github/FUNDING.yml
F-Droid donation metadata where appropriate
```

A safe GitHub funding template is provided as:

```text
.github/FUNDING.yml.example
```

It is intentionally not named `FUNDING.yml` yet.

## Commercial support

No separate paid support or service-level agreement is currently promised by
this repository.
